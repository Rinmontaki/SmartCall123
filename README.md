# SmartCall 123

Sistema de Gestión y Priorización Dinámica de Llamadas de Emergencia mediante Pilas y Colas.

## Descripción

SmartCall 123 es un proyecto académico desarrollado en Python para gestionar temporalmente llamadas recibidas por una central de emergencias.

El sistema utilizará colas FIFO para organizar las llamadas según su nivel de prioridad y una pila LIFO para registrar y revertir operaciones.

## Tecnologías

- Git
